# L&B Artigos Escolares

Landing page estática para a L&B Artigos Escolares, uma loja de materiais e artigos escolares. O projeto foi construído a partir de um template HTML/CSS/JS (Bootstrap + jQuery) e não possui etapa de build.

## Tecnologias

- HTML5
- CSS3 (Bootstrap)
- JavaScript (jQuery e plugins)

## Como visualizar

Não há dependências para instalar nem servidor para rodar. Basta abrir o arquivo `index.html` diretamente no navegador.

## Estrutura

- `index.html` — página principal
- `css/` — folhas de estilo (Bootstrap e estilos customizados)
- `js/` — scripts (jQuery e plugins usados pelo template)
- `images/` — imagens do site
